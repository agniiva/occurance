# Archive

Retired essays, taken off the live site in November 2026. Hugo does not build this folder, so nothing here is published on www.agnivamahata.com.

- `writing/`: the essays.
- `og/`: their social-preview images.

To republish an essay, move `writing/your-post.md` back to `content/writing/` and `og/your-post.png` back to `static/og/`. The Writing page, navigation link, and homepage section return on their own once a post is published.
